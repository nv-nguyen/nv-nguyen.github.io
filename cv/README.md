# CV

LaTeX source of the CV linked from the homepage (`static/download/cv_nguyen.pdf`).

Build with [Tectonic](https://tectonic-typesetting.github.io/) (XeTeX), from this folder:

```sh
tectonic cv_nguyen.tex
cp cv_nguyen.pdf ../static/download/cv_nguyen.pdf
```

Fonts: Montserrat (SIL Open Font License, see `fonts/OFL.txt`), loaded from `fonts/`.
